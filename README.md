## こんな人のためのアプリです

新大学一年生

## 解決する困りごと

毎朝の準備の場面で、様々な情報源を見て見落としていないか不安になる気持ちを、持ち物を一目瞭然にすることで解決するアプリ。

---

## 使い方

1.  今日持っていくものを確認するブラウザでアプリを開きます。   画面上部に今日の日付が表示され、その下に「今日必要な持ち物」だけが一覧で表示されます。 
2. 新しい持ち物を登録する画面下の「持ち物名」の入力欄に、持っていくものを入力します。「日付」を選択します。「追加」ボタンを押すと、リストに登録されます。 
3.  不要になった持ち物を消す登録を間違えたときや不要になったときは、持ち物の右側にある「削除」ボタンを押します。   リストから該当の持ち物が消去されます。

## 主な機能

| 機能 | 説明 |
|---|---|
| 画面表示 | 登録されたデータの中から、今日の日付と一致する持ち物・課題のみを自動で抽出し、カード型リストで表示します。|
| 持ち物管理 | 「持ち物名（テキスト）」と「対象日付」を指定して、リストに新しいアイテムを登録します。   空文字などの不適切な入力を防ぐチェック（バリデーション）を行います。誤って登録したアイテムや、不要になった持ち物をリストおよび保存データから消去します。 |
| データ保存 | 登録や削除を行った持ち物データをブラウザ内に自動保持します。
ページの再読み込み（リロード）やブラウザの再起動を行っても、データが消えずに復元されます。 |

## ローカルで動かす方法

このアプリは HTML / CSS / JavaScript だけでできています。
特別な準備は必要ありません。

1. このリポジトリをダウンロード（または `git clone`）します。
2. `index.html` をブラウザで開きます。

> VS Code で開いている場合は、Live Server 拡張を使うと確認が楽です。

## 注意
